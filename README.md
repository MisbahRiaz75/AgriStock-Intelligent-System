# AgriStock Intelligent System

Inventory and expiry tracking system for agriculture medicine.

## Based on
Built on top of an open-source PHP inventory management system by Siamon Hasan (MIT License), customized for agriculture medicine stock and expiry tracking.

## Technologies
PHP, MySQL, HTML, CSS, JavaScript (XAMPP)

## How to run
1. Copy the project folder into xampp/htdocs
2. Import the .sql file using phpMyAdmin
3. Open localhost/project-folder-name in the browser
